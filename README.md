# Introduction to Stata

This guide is suitable for both beginners and experienced Stata users. You can work through the guide from start to finish or use it to find help with a specific topic. It covers how to import and explore data, create graphs, create new variables, and save and manage your data.

The dataset used is a modified version of the Canadian Community Health Survey (CCHS), 2022 Annual Component. The CCHS is a national health survey conducted by Statistics Canada. This guide uses the CCHS dataset for teaching purposes. For simplicity, the survey weights are not applied. As a result, the findings presented in this guide are not representative of, and should not be generalized to, the Canadian population. Instead, the findings describe only the sample.
